# 🧮 ScholarCalc — Advanced Scientific Calculator for JEE Aspirants

> A modern, research-grade **Scientific Calculator** built using Python and Tkinter — crafted for **JEE aspirants**, engineering students, and curious researchers who seek *power, precision, and aesthetics.*

---

## 🌟 Features

- ⚙️ **Full Scientific Functionality**
  - Trigonometric (`sin`, `cos`, `tan`), logarithmic, exponential operations  
  - Integration, differentiation, symbolic evaluation (`SymPy` powered)  
  - Fractional part, floor/ceil, GIF, factorial, modulus  
  - Square root, nth power, constants (π, e), and more

- 🎨 **Apple-Inspired Modern UI**
  - Minimalistic rounded design  
  - Hover effects and responsive layout  
  - History tab for past calculations  
  - Highlighted "=" button (orange-white focus)

- ⚡ **Error-Free & High-Performance**
  - Built on **pure Python** with clean modular code  
  - Lightweight — no lag, no complex dependencies  
  - 100% local execution (safe and offline-ready)
